Who I am

I'm a fresher DevOps & Cloud Engineer with hands-on experience building real infrastructure on AWS — not just following tutorials, but architecting and deploying production-style systems from scratch.

I've built end-to-end CI/CD pipelines, observability stacks, and serverless applications — provisioned with Terraform and deployed through GitHub Actions using OIDC authentication. I care about infrastructure that is reliable, observable, secure, and cost-conscious — the qualities that matter when systems move beyond the development environment.
